Architecture

Moderation saves the status and audit record in one transaction. A change stream on moderation events wakes the worker. The worker finds the ring, upserts session alerts, saves its resume token, then recomputes the linked verdicts, so alerts never wait for verdicts. The SSE route watches alerts and filters by the anonymous session cookie.

Open /under-the-hood to show actual database evidence. Ring traversal uses a multikey identifier index and graphLookup. Photo matching uses indexed hash bands. Scam-script matching uses vector search through the shared helper; copied text is detected by 3-word phrase overlap, without embeddings.

Complete the two-browser acceptance before presenting that flow as demonstrated. The current price signal uses RTB average rents and a room factor, rather than the original plan's median. Sources: CONTRACT.md, lib/fanout.ts, scripts/worker.ts, lib/signals/priceLow.ts and the API routes in this repository.
